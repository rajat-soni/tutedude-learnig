**Task No-18 Color selection and user display**

* This project demonstrates the use of JavaScript DOM Manipulation and Even Handling.
* Select a Color by clicking on a color box.
* Change the background color of selected box.
* Enter text into an input field.
* Display the entered text on the screen when the button is clicked.
* I uses querySelectorAll() to select multiple elements.
* I Uses addEvenListerner() to handle click events.
* I uses event.target.id or value to get id or value of click Elements.
* I use gelElementsById to get Elements id.
