**Task No-17 Promise Based divide functions**

**This project demonstrates the  use of a javaScript Arrow function  that returns a Promise.**
* Create an arrow function that takes two number and return a Promise.
* The Arrow function perform the division of two Numbers.
* if the second number is '0' return  the promis with an error message.
* Otherwise resolve promise with division result.
* .then() use for handle result.
* .catch() use for handel error.
